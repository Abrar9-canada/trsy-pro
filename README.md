# TRSY - نظام إدارة الوكالات (Agency Management System)

نظام متكامل لإدارة وكالات الخدمات الرقمية، مصمم لربط الإدارة بالمناديب وتتبع الطلبات، العمولات، والعمليات المالية بشكل لحظي وآمن.

## 🚀 المميزات الرئيسية
- **لوحة تحكم ذكية:** عرض حي للإحصائيات والأرباح.
- **إدارة الطلبات:** تتبع كامل لحالة العميل من الطلب وحتى التسليم.
- **نظام العمولات:** احتساب تلقائي لعمولات المناديب مع توثيق إيصالات الدفع.
- **تنبيهات لحظية:** إشعارات فورية عبر Supabase لكافة العمليات الهامة.
- **سجل رقابي (Audit Trail):** تسجيل كافة الحركات لضمان الشفافية والرقابة.

## 🛠 التقنيات المستخدمة
- **Frontend:** Next.js, Tailwind CSS, React.
- **Backend/Database:** Supabase (PostgreSQL).
- **Authentication:** Supabase Auth.
- **Deployment:** Vercel.
